# Sonhália: demonstração

Demonstração navegável do **Sonhália: o Mundo Encantado do Hangul**, uma cartilha de coreano para falantes de português com um app em formato de mundo mágico.

Concebido e dirigido por Jacqueline.

## Como experimentar

Abra a página publicada e, na tela inicial, ative o código de teste `KOR-3F8M-2LQW`. Depois escolha um bichinho e explore o mapa, a casa e a loja. O código `KOR-USED-0000` simula um código já usado.

## O que é só demonstração

- Todos os dados são de exemplo, e o progresso **não é salvo** ao recarregar a página.
- Não há login, banco de dados nem servidor. Os desafios corrigidos pela professora são simulados.
- O nome "Sonhália" é provisório.
- As traduções e as classes de palavra ainda não foram revisadas por uma pessoa nativa.
